Indian Liver Patient Dataset – Tableau Visualization

📊 About the Project

This project is based on the Indian Liver Patient Dataset (ILPD). The main goal of this project is to explore the dataset and understand the different factors related to liver disease using Tableau.

I created different types of visualizations such as bar charts, box plots, tables, and continuous charts to make the data easier to understand and identify useful patterns.

The project is mainly focused on data exploration and visualization, rather than building a machine learning model.


📁 Dataset

The dataset contains information about 583 patients and includes different medical and demographic attributes.

Some of the important columns are:

* Age – Age of the patient
* Gender – Gender of the patient
* Total Bilirubin – Total bilirubin level
* Direct Bilirubin – Direct bilirubin level
* Total Proteins – Total protein level
* Albumin – Albumin level
* A/G Ratio – Albumin and globulin ratio
* SGPT – SGPT enzyme level
* SGOT – SGOT enzyme level
* Alkphos – Alkaline phosphatase level
* Is Patient – Indicates whether the patient is classified as a liver patient

The dataset contains 441 male patients and 142 female patients.

There are 416 records classified as liver patients and 167 records classified as non-liver patients.


📈 Tableau Visualizations

I created multiple visualizations in Tableau to explore the dataset from different perspectives.

1. Bar Chart

The bar charts are used to compare categories and understand differences between groups, such as:

* Patient distribution
* Gender distribution
* Liver patient vs non-liver patient counts
* Other categorical comparisons

These charts make it easier to see which categories have higher or lower numbers of patients.

2. Box Plot

Box plots are used to understand the distribution of numerical values and identify possible outliers.

I used them to explore variables such as:

* Age
* Bilirubin levels
* Protein levels
* Albumin
* SGPT
* SGOT
* Alkaline phosphatase

The box plots help show the median, spread of the data, and unusual values in the dataset.

3. Table

Tables were created to display the actual values and make detailed comparisons between different variables.

This is useful when a chart gives an overall idea but the exact values are also important.

4. Continuous Charts

Continuous charts were used to visualize numerical variables and observe how values are distributed across the dataset.

These visualizations help in understanding relationships and patterns between different patient attributes.


🔍 Some Observations

While exploring the dataset, a few interesting points stood out:

* The dataset contains considerably more male patients than female patients.
* A larger portion of the records are classified as liver patients.
* Some numerical variables contain noticeable outliers, which can be seen more clearly using box plots.
* The medical measurements vary significantly between patients.
* There are 4 missing values in the `alkphos` column, while the other columns do not contain missing values.
* Visualizing the data makes differences and distributions much easier to notice compared with looking at the raw CSV file.
